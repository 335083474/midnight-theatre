# Midnight Theatre

Frontend for a Paper Chase single-investigator and same-location party playtest.

[Open the website](https://335083474.github.io/midnight-theatre/)

Create a room for a single investigator or a same-location party of 2-6 with MiniMax. Each party member joins through an invitation QR, holds a separate character and private notebook, and takes turns acting; witnesses resolve SAN individually. This is an adapted group playtest, not an official multiplayer edition. The independent Cloudflare backend supports accounts, account-bound saves and server-owned dice; guest rooms expire after seven days. Clerk Google/email login is connected to a development instance for internal testing only; legacy accounts and saves remain available. TVs join with the eight-character room code; each investigator sees only their own private notes and unshared materials. Includes a free original short investigation, a unified creator workbench with private scenario editing, media management, MiniMax image-01 support, aggregate play/test revenue data, reviewed publication, and an internal Paper Chase test. Purchase rehearsal includes isolated simulated orders. Stripe sandbox checkout is connected with a restricted test key and signed test webhooks; real charging remains disabled. Uses an adapted test investigator and documented timing choices; not a general CoC engine or an officially reviewed product.

No-room query routes and demo code CTH192 retain the original synthetic UI walkthrough.

Only compiled frontend files and generated atmospheric artwork are published here. No scenario PDF, private pack, backend source, credentials, or campaign records are included. This is an unofficial prototype, not a Chaosium product.
