# Midnight Theatre

Frontend for a single-investigator Paper Chase playtest.

[Open the website](https://335083474.github.io/midnight-theatre/)

Create a room to start a single-investigator investigation with MiniMax. The independent Cloudflare backend supports accounts, account-bound saves and server-owned dice; guest rooms expire after seven days. Clerk Google/email login is connected to a development instance for internal testing only; legacy accounts and saves remain available. TVs join with the eight-character room code; only the investigator sees private notes. Includes a free original short investigation, private scenario authoring and an internal Paper Chase test. Purchase rehearsal includes isolated simulated orders. Stripe sandbox checkout requires operator test configuration; real charging remains disabled. Uses an adapted test investigator and documented timing choices; not a general CoC engine or an officially reviewed product.

No-room query routes and demo code CTH192 retain the original synthetic UI walkthrough.

Only compiled frontend files and generated atmospheric artwork are published here. No scenario PDF, private pack, backend source, credentials, or campaign records are included. This is an unofficial prototype, not a Chaosium product.
